Database carte

Il tool parte con le sole carte della banlist. Scarica un database per avere autocomplete completo, riconoscimento Extra Deck automatico, immagini ed export .ydk (che richiede gli ID carta).

⚠ La legalità del pool è legata al formato/banlist attivo (selezionabile nel tab Banlist), non a "Edison" in modo fisso. Sia "Pool del formato attivo" sia "Tutte le carte" definiscono quali carte sono legali nel formato attivo; con "Tutte le carte" hai la ricerca su tutto, e l'opzione "Solo formato attivo" nasconde/blocca ciò che non appartiene al formato.

Lo scarico avviene dal tuo browser. Se apri il file da locale e fallisce (rete/CORS), usa l'import manuale qui sotto.

Importa database da file/testo

Lingua italiana

Scarica i nomi italiani e li abbino via ID carta alle carte già presenti (l'inglese resta come riferimento per la banlist). Poi puoi passare a IT dall'interruttore "Lingua" nella schermata Costruisci mazzo. Le carte senza traduzione restano in inglese.

Confronta due liste

Incolla due decklist. Usa intestazioni di sezione (opzionale): Main Deck / Extra Deck / Side Deck. Righe: 3x Nome, 3 Nome o Nome.

Dati banlist: Format Library (formatlibrary.com). Database carte e immagini: YGOPRODeck (ygoprodeck.com) — API pubblica, usata con un solo download in cache. Strumento non ufficiale, non affiliato a Konami.
